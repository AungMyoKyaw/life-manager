# Code of conduct

This project follows the Contributor Covenant, version 2.1.

## In short

- Be respectful. Assume the other person is doing their best.
- Accept constructive criticism gracefully, and give it kindly.
- Focus on what is best for the user of this app.
- Show empathy towards other users and contributors.

## Unacceptable behaviour

Harassment, personal attacks, sexualised language, public or private harassment, publishing private information, and any other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This applies in the repository, in issues and pull requests, and in any space where someone is representing the project.

## Enforcement

Report a problem to the maintainer through the private reporting route in `SECURITY.md`, or by opening an issue if it is not a security matter and you are comfortable doing so. Reports are handled confidentially. The maintainer will acknowledge a report, review it, and decide on a response, which may include a warning, a temporary ban or a permanent ban.
